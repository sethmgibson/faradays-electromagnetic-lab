# Faraday's Electromagnetic Lab

Local copies of Faraday's Electromagnetic Lab, a PhET simulation for exploring electromagnetic induction. The five scenes are Bar Magnet, Pickup Coil, Electromagnet, Transformer, and Generator. Move a magnet or a coil, change the number of loops, and watch the magnetic field and the induced current.

These copies are development builds of version 1.1.0-dev.0 from October 2024, made with PhET's `adapted-from-phet` brand. They are not an official release published by PhET.

## Open the lab

Open an HTML file in a current desktop browser. Nothing needs to be installed or built. Double-click the file, or drag it into a browser window.

- `faradays-electromagnetic-lab_en_adapted-from-phet.html` is the English build from 2024-10-04. Language switching is off.
- `faradays-electromagnetic-lab.html` is the same English build, stored under a second name.
- `faradays-electromagnetic-lab_all_adapted-from-phet.html` is the all-locales build from 2024-10-02. It starts in English and can switch language.
